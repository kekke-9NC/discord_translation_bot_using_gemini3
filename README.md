# Discord Translation Bot using Gemma 4

A Discord bot that provides multilingual channel translation, server-specific glossary support, and AI-powered reply suggestions using Google's Gemma 4 model through the Gemini API.

## Features

- **Bidirectional Translation**: Automatically translates messages between paired Japanese and English channels.
- **Context-Aware**: Uses conversation history (last 10 messages) to provide context-aware translations.
- **Message Synchronization**: Edits and deletions in the source channel are reflected in the translated channel.
- **Reply Suggestions**: reply suggestions generated by Gemma 4, visible only to the user (ephemeral-like).

## Requirements

- Python 3.10+
- Discord Bot Token
- Google AI Studio API key with access to Gemma 4

## Setup

1.  **Clone the repository**
    ```bash
    git clone https://github.com/kekke-9NC/discord_translation_bot_using_gemma4.git
    cd discord_translation_bot_using_gemma4
    ```

2.  **Install Dependencies**
    ```bash
    pip install -r requirements.txt
    ```

3.  **Configuration**
    Copy the example files and replace their placeholder contents with your own credentials:
    ```bash
    cp discord_token.txt.example discord_token.txt
    cp gemini_api_key.txt.example gemini_api_key.txt
    ```
    Paste your Discord Bot Token into `discord_token.txt` and your Google AI Studio API key into `gemini_api_key.txt`. Keep these private files out of version control; they are ignored by Git.

    After starting the bot, use `/pair_add` in your server to choose the source and destination channels and their languages.

4.  **Run the Bot**
    ```bash
    python bot.py
    ```

## Usage

-   **Channel pairing**: Use `/pair_add` and `/pair_remove` in Discord.

## Server setup and multilingual translation

Use `/pair_add` in a server to connect two text channels and set their language names or codes (for example `Japanese` and `English`, or `ja` and `fr`). The bot translates posts from either channel to the other. `/pair_remove` removes a pair. These commands require the **Manage Server** permission.

Use `/glossary_add` to define a server-specific term with its source and target languages, `/glossary_remove` to delete it, and `/glossary_list` to view terms for a language direction. Glossary changes are limited to users with **Manage Server**; terms are stored separately for each Discord server and language direction.

Replies to mirrored messages link to the corresponding mirrored message. Source threads are mirrored as threads in the paired channel, and message/thread correspondence is persisted in `bot.sqlite3` so replies continue to work after a restart. Raw edit/delete events use these saved links even when the source message is no longer in discord.py's in-memory cache. Keep this database file backed up with the bot's configuration.

Both translation and reply suggestions use `gemma-4-26b-a4b-it` by default. Set `GEMINI_MODEL` to override the model for both features and `BOT_DATABASE` to place the SQLite database elsewhere. Enable the Message Content intent in the Discord Developer Portal and grant the bot view/send permissions in both paired channels; it also needs permission to create threads to mirror source threads.
